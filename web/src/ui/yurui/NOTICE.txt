Local modifications, 2026-10-20:
- The local design system is named yurui; component paths and internal style identifiers use yurui.
- Component imports use local module paths.
- PopoverContent and DialogContent require explicit portal containers for Shadow DOM isolation.
- Theme root selectors target :host and :host(.dark).
- Theme and component materials use a local matte stationery design with warm paper, flat ink colors, ticket labels and offset print shadows.
- Controls share theme recipes; poster cards use unglazed, uncropped covers and ruled metadata sections.
- Display typography uses system rounded/CJK families.
